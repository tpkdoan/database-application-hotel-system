# Airbnb Web Application

Owner: Pham Khanh Doan Tran - s3978798\

This project is a web application for managing Airbnb-like listings using Node.js and Express, with MongoDB as the database.


## Requirements

- Node.js (version 14.x or higher recommended)\
- MongoDB (version 3.6.0 or compatible)\


## Installation Instructions

1. Clone this repository to your local machine.
2. Navigate to the project directory.
3. Install the required dependencies: 


## Starting the Server

1. Make sure MongoDB is running on your local machine.
2. Start the server with the following command:  **nodemon**
3. Open your browser and navigate to  **http://localhost:3000** to access the application.

## Port
The application runs on **port 3000** by default.


## Dependencies

The following libraries are required and are installed via  **npm i**:
- express - Framework for handling server requests and responses.
- body-parser - Middleware for parsing incoming request bodies.
- mongodb - MongoDB driver to connect to the MongoDB database.
- nodemon - Utility that automatically restarts the server when file changes are detected.


## Notes
